## description of the problem


Theres a safe  
dial ranges from 0-99
dial starts at 50  
puzzle input is a sequence of f"{direction}{steps}" strings  
one in each line    
left (toward lower numbers) or to the right (toward higher numbers).  

### part 1  
The password is the number of times the dial is left pointing at 0 after any rotation in the sequence.  

### part 2
The actual password is number of times the dial passes through or stops at 0
